# Student Learning & Course Portal

## Project Overview
Student Learning & Course Portal is a responsive web application that allows students to explore courses, view course information, enroll in programs, and monitor their learning progress.

## Objectives
- Develop interactive frontend applications.
- Implement JavaScript DOM manipulation.
- Understand JSON and JavaScript objects.
- Implement search and category filtering.
- Store student data using LocalStorage.
- Create responsive user interfaces.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON
- LocalStorage
- Git
- GitHub

## Features
1. Dynamic course listing.
2. Course detail view.
3. Search functionality.
4. Category-based filtering.
5. Course enrollment.
6. Lesson completion tracking.
7. Student dashboard.
8. LocalStorage data persistence.
9. Responsive design.

## Installation
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Explore and enroll in available courses.

## Storage
LocalStorage is used to save enrolled courses and learning progress in the browser.
